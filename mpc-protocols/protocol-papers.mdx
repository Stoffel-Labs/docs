An associated paper identifies a construction, not an implementation certification. Explicit references occur in source comments or repository guidance. Inferred references identify recognizable algebra or state-machine ancestry. Background references explain a primitive or limitation. Read the [security matrix](./security-model) and [cost reference](./protocol-costs) alongside this map.

## Inferred and foundational associations

| Implementation | Associated paper | Boundary |
| --- | --- | --- |
| Shamirshare, NonRobustShare and RobustShare polynomial representation | Shamir, *How to Share a Secret* [9] | Bare sharing is not VSS and does not authenticate a dealer. |
| FeldmanShamirShare coefficient commitments and verification | Feldman, *A Practical Scheme for Non-interactive Verifiable Secret Sharing* [10] | Coefficient commitments are not hiding. The surrounding asynchronous protocol must independently supply agreement and recovery. |
| PedersenPolyCommitment | Pedersen, *Non-Interactive and Information-Theoretic Secure Verifiable Secret Sharing* [11] | Only the commitment helper is present. Correct setup requires an unknown discrete-log relation between generators. |
| Beaver multiplication in both backends | Beaver, *Efficient Multiparty Protocols Using Circuit Randomization* [12], with the exact masked identity in HoneyBadgerMPC section 2.2 [1] | Requires fresh, correct correlated triples. |
| Bracha INIT/ECHO/READY | Bracha, *Asynchronous Byzantine Agreement Protocols* [13]; algorithms also described in [3][4] | Reliable broadcast is not agreement on an arbitrary input set and is not guaranteed to deliver when its dealer never starts. |
| ABA EST/AUX/common-coin rounds | Mostefaoui, Moumen and Raynal [16], via the HoneyBadgerBFT appendix [4] | The concrete coin, message ordering, termination and session lifecycle must match the protocol assumptions. |
| ACS | Ben-Or, Kelmer and Rabin, *Asynchronous Secure Computations with Optimal Resilience* (PODC 1994), identified as reference 9 in HoneyBadgerBFT [4] | RBC plus one ABA per proposer, not a union of locally received values. |
| Threshold-signature common coin and trusted key Dealer helper | Boldyreva, *Threshold Signatures, Multisignatures and Blind Signatures Based on the Gap-Diffie-Hellman-Group Signature Scheme* (PKC 2003), identified as reference 11 in [4] | Pairing-based threshold signature ancestry. `Dealer::distribute_keys` is trusted setup, not distributed key generation. |
| Degree reduction by resharing local products in AVSS TripleGen | Ben-Or, Goldwasser and Wigderson [15] plus Beaver [12] | Algebraic ancestry only. VSS of a claimed product does not prove multiplication correctness. |
| Reed–Solomon encoding/error correction | Reed and Solomon, *Polynomial Codes Over Certain Finite Fields* (1960); the code and decoding prerequisites are reviewed in AVID [3], with the concrete decoder mapped to Gao [6] | Byte erasure coding and field-polynomial error correction are distinct code paths. |
| Delay-independent consensus limitations | Fischer, Lynch and Paterson [14] | Background impossibility theorem, not a protocol implementation. |


The original FNT source URL is unavailable. The related Soro–Lacan paper [17] is linked separately rather than silently substituted. Full secret-divisor fixed-point division, complete hbACSS and unmerged protocol branches are outside this revision.
